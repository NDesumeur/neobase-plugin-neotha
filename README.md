# NeoTha

Jeu de rythme à la souris, inspiré du gameplay de Rhythia : les notes arrivent depuis le fond d'un tunnel sur une grille 3×3, il faut avoir le curseur dessus à l'instant où elles se posent (plus on est au centre, meilleure est la note).

- Les 200 morceaux et leurs 4 niveaux de difficulté de **Rythme**.
- « Mes musiques » : crée des niveaux automatiquement depuis un fichier audio ou n'importe quelle musique de **NeoMusic** (tempo et temps forts détectés).
- Espace : jouer / reprendre · P ou Échap : pause.

Nécessite le plugin NeoMusic. Les records sont propres à NeoTha.
